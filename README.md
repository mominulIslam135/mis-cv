# MD Mominul Islam Pramanik — Portfolio

Personal portfolio & CV site — Senior Application Engineer (AMI · HES · MDM · Full-Stack).

Live at: https://mominulislam135.github.io/mis-cv/

Built with plain HTML, CSS and vanilla JavaScript (no build step) — dark/light theme toggle,
scroll-reveal animations, animated stats, and a downloadable PDF résumé.

## Structure

- `index.html` — page markup
- `assets/css/style.css` — styles & theme tokens
- `assets/js/script.js` — interactivity (theme toggle, nav, reveal animations, typed text, counters)
- `assets/img/` — profile images
- `assets/Mominul_Islam_Pramanik_CV.pdf` — downloadable résumé

## Run locally

Any static file server works, e.g.:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.
